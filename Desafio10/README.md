DESAFIO 10

O programa compara os algoritmos Selection Sort e Insertion Sort utilizando conjuntos de 100, 1.000 e 10.000 números inteiros. 
Para cada teste, os dois algoritmos recebem os mesmos dados, permitindo uma comparação justa. 
Estão sendo contabilizadas as comparações, movimentações e o tempo de execução de cada algoritmo, conforme solicitado no documento do hackathon pelo Prof. Alex.
O Selection Sort possui complexidade O(n²) nos melhores, médios e piores casos, enquanto o Insertion Sort possui O(n) no melhor caso e O(n²) no caso médio e pior caso.
Os resultados mostram como o aumento da quantidade de elementos influencia o desempenho dos algoritmos, mostrando então que ambos podem se tornar lentos para conjuntos maiores. 
valores exatos de tempo, comparações e movimentações devem ser obtidos executando o programa no computador utilizado.
